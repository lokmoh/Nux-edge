# Nux-edge

Nux-edge 是一个完全运行在 Cloudflare Workers 上的 MCP 网关。它把多个上游 MCP 服务聚合成一个入口，代为托管上游认证，并能用一份 JSON 插件把普通 HTTP API 桥接成 MCP 工具。

客户端只连接 Nux-edge。上游的地址、凭据和协议差异留在网关这一侧。

## 要解决的问题

### 无头环境无法完成 OAuth 登录

服务器、容器、CI 和嵌入式设备没有浏览器，连不上要求浏览器授权的远程 MCP。

Nux-edge 在一台能登录的环境里完成一次授权，并把上游凭据留在网关。其余机器只持有 Nux-edge 签发的访问令牌。

### 配置分散

每个客户端都要各自配置每个上游。上游一变，所有客户端一起改。

Nux-edge 让客户端只配置一个地址，就能看到所有上游的工具。

### 大量 API 没有 MCP

只有 REST API 的服务无法被 Agent 直接使用。

Nux-edge 让任何人用一份 JSON 插件把它变成 MCP 工具，不需要为每个 API 单独写一个 MCP 服务。

## 工作模式

### 中转模式（Relay）

代理已有的远程 MCP 上游。网关托管其凭据，聚合工具，并按权限对外暴露。

### 桥接模式（Bridge）

按插件 JSON 把 HTTP API 映射成 MCP 的 tools。resources 与 prompts 留到后续版本。

## v1 非目标

下面这些明确不做。实现 v1 时不要自行扩展进去：

- 不支持 stdio 型上游。Workers 无法启动子进程。
- 不做多租户 SaaS、计费和公共插件市场。v1 面向单用户或小团队自部署。
- 插件只能声明式描述 HTTP 请求，不允许携带或执行任意代码。
- 不托管、不执行用户上传的服务端代码。
